# Instrucciones del proyecto

Conservar el texto pendiente de las notas entre reinicios, incluidas las que ya tienen archivo. El primer inicio debe mostrar una nota vacía, sin pestaña de bienvenida.

Preparar y verificar todos los cambios antes de solicitar aprobación. Pedir aprobación explícita del usuario antes de hacer commit y push a `beta`. No ejecutar esas acciones hasta recibirla.

Solo el usuario puede autorizar merge y push a `main`. Esperar una indicación posterior y su aprobación explícita para ambas acciones; la aprobación para `beta` no autoriza cambios en `main`.
